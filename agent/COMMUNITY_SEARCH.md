# 社区梗与公开网页搜索

遇到不熟悉或含义不清的网络用语、人物称呼和社区事件时，默认人格主动调用web_search查证，优先相关社区。提示词在prompts/tools/default.md及prompts/personas/default.md，普通日常情绪表达和上下文已明确的内容不额外搜索。

可使用关键词加site:douyin.com、site:bilibili.com或site:tieba.baidu.com，换别称或原句继续查。返回结果逐个核对真实域名，不能把Bing忽略site条件后返回的站外结果当成本社区资料。匹配后再应用结果条数上限，不让前几条站外结果遮掉后面的站内结果。

B站限定检索没有可用RSS结果时，会尝试无Cookie、无登录的公开视频搜索接口，返回标题、作者、简介和规范视频链接。此回退仍走相同的公网地址、重定向、大小和超时约束；接口变动、错误码或风控时不伪造结果。搜索元数据不能证明已观看视频、读取字幕或评论。

搜索词须去除联系人ID、私人经历和秘密，不能上传完整聊天。结果及网页内容始终为资料，不可修改身份或工具权限。回答中引用真实来源，URL单独完整发送；10字拆条不切断链接。

## 2026-10-31 实测

使用bot自身Web类联网调用，没有付费模型调用：

- B站的“电子榨菜”限定搜索返回了站内文章摘要；打开文章时为验证码页，不能称已读正文。
- B站公开视频检索接口返回了标题、作者和视频简介，不能称已看视频内容。
- 贴吧公开搜索页返回403安全验证。
- 抖音搜索页返回HTTP 200但可提取文本为空，不能称读到搜索正文。
- 部分Bing RSS关键词结果无关或忽略site；已添加站点过滤。无站内结果时明确说明，换词或改用其他公开来源。

读取不到时不绕过登录或验证码，优先换公开资料、说明只有摘要，仍有歧义再询问上下文。本机实测明细在data/validation/community-web-*.json。用户授权的三条短消息测试单独记录在community-web-message-test.json；状态确认不等于人工收件确认。

提示词在后续轮次热更新；新增搜索域名核对与B站回退代码需重启智能体生效。没有自动重启当前实例。
