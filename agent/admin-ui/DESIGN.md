# 小鲸鱼 · 消息观察台

## 设计计划

核心任务不是统计机器人有多忙，而是判断一条消息现在走到哪里、模型说了什么、每条出站是否有可核对的结果。选择「可阅读的事件时间线」，不做图表、仪表盘卡墙或虚构活动流。

- 色彩：海蓝 `#1666B0`（选中与操作）、深蓝墨 `#16334D`（正文）、雾蓝 `#ECF4FA`（选区）、航道灰 `#5D7285`（次要说明，经过浅海背景 4.5:1 对比度校正）、白 `#FFFFFF`（内容）、浅海 `#F4F8FB`（工作台背景）。状态以图形和文字共同表达，使用独立的绿/琥珀/红语义色；unknown 始终是「需核对」，不暗示送达。
- 字体：中文优先本机「Microsoft YaHei UI / PingFang SC」，正文与标题统一无衬线；关联 ID 使用 Consolas，仅对齐时间与数值时启用等宽数字。正文 14px，主标题 22px，元数据 12px。
- 布局：左对齐，固定窄导航、可搜索消息索引、所选消息阶段时间线。导航的鲸鱼轮廓与纵向「航道」时间线是仅有的辨识性视觉，其他结构服务信息。

```text
┌────────┬───────────────────────┬────────────────────────────────────┐
│ 鲸鱼   │ 消息记录   同步状态     │ 消息详情                 刷新      │
│ 消息   │ 搜索 / 状态筛选        │ 入站正文 · 时间 · 关联 ID          │
│ 表情   ├───────────────────────┤ 01 收到消息                        │
│        │ 会话、摘要、阶段       │ 02 模型处理 / 最终回复 / 工具 / usage│
│ 本地   │ 可滚动，不抢选择       │ 03 出站记录 / 每条独立状态           │
└────────┴───────────────────────┴────────────────────────────────────┘
```

窄屏改为消息列表与详情的明确前后页；表情库复用导航，静态封面按需加载，只有主动预览播放 GIF。预算与本地服务状态收于次要来源面板。页面无外部字体、CDN 或第三方请求。

## 对照审视与修订

否决通用后台的「四张大数字卡 + 折线图」：它不能回答某条消息卡在哪一步。改用真实阶段顺序与每条出站的明确证据。也不以整块海蓝填充卡片；海蓝仅用于导航、选中细边和动作，让中文正文主导。无实时记录时保留诚实空态，旧记录缺 trace、连接中断和加载分别解释，不自动用伪造进度补齐。

## 实施约束

消息/图库只读 API，固定同源服务控制按钮；输入文本以 textContent 呈现；图片 URL 验证同源与限定 API 路径；搜索防抖及请求序列控制；轮询不改选中项，不重置滚动；页面隐藏降频；可键盘操作、明确焦点、尊重减少动画。时间线是语义列表，阶段颜色均有图标和文字，不使用纯颜色编码。对文本和状态运行 WCAG 对比度计算，不套用不适用于状态颜色的分类序列验证。

服务操作位于主标题下的轻量状态栏：分别显示bot和桥接状态，提供开启/停止两个按钮；启动/停止期间双按钮禁用，失败时保留实际状态并提示查看本地日志。窄屏状态栏自然换行，不遮挡消息内容。
