消息区域仅从当前本地管理服务读取记录，不提供发送或重试按钮。服务按钮仅开启或停止本项目的机器人与桥接；开启后机器人会恢复自动回复，不修改配置。模型区只展示最终回复、工具摘要和用量，不展示系统提示词、上下文、密钥或思维链。

本页可能包含聊天内容。请勿在不受信任的设备上打开或分享屏幕。历史记录缺少追踪时不推测关联；提交成功不等于对方实际收到。

管理台后台

只关闭本页面后台，bot 与微信桥接继续运行。关闭后需重新运行 start-admin.cmd 才能再次打开管理台。

关闭管理台后台？

只关闭 Web 管理台，不停止 bot 或微信桥接。当前页面将不再更新；需要重新运行 start-admin.cmd 才能再次打开。
