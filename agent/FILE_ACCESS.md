# 文件交付与沙箱外授权

模型使用 `send_file({path})` 把当前会话沙箱内的文件作为微信文件发送给当前会话。支持各种文件类型，单文件最多10MiB，保留文件名。发送前固定一份副本，因此原文件随后变化不会改变已排队的内容；同一执行中重复提交相同文件不会重复发送。`queued` 只代表排队，不表示对方已收到。发出的文件名会进入当前会话历史。

文本可通过 `workspace_write` 生成；收到的附件和已批准导入的宿主文件也可交付。模型不能指定任意收件人，也不能直接把宿主路径传给 `send_file`。

## 管理台会话授权

管理台“会话权限”可为每个联系人或群聊独立设置 Bot 开关和文件范围。仅沙箱禁用宿主操作；任意路径允许 `external_list/read/write` 直接访问本机文件；按任务确认则由指定联系人批准本次任务。文件大小、系统账户权限及路径检查保持生效。文件工具本身不执行命令；另启用 Codex 时的权限见 [CODEX.md](CODEX.md)。切回仅沙箱或关闭 Bot 后，后续宿主操作会被拒绝。

未设置管理台覆盖时，保持原有白名单；配置 `externalAccess` 的会话使用下面的按任务确认机制。详见 [ADMIN.md](ADMIN.md)。

## 每个任务确认一次

启用 `externalAccess` 并配置 `approver` 后，模型可使用：

- `external_list({path, reason})`：申请列出绝对目录的前100项，不递归。
- `external_read({path, reason})`：申请读取一个绝对路径文件，复制到当前沙箱；小于64KiB的UTF-8文件同时返回文本，图片可再用 `read_image` 查看。
- `external_write({path, sourcePath, reason})`：申请将沙箱文件的固定内容写入绝对路径，覆盖已有文件，父目录必须存在。

本次任务第一次访问宿主文件时，向配置联系人的私聊发送申请，说明来源、任务用途、首个操作及后续读写范围。联系人直接回复 **`/bot allow`** 确认或 **`/bot deny`** 拒绝，不需申请编号。一次确认覆盖同一任务后续的列目录、读取和写入；不会给会话永久授权，也不授权执行命令。任务指一次回复执行，同一 `inputId` 的工具调用共用授权；新任务重新申请。

同一联系人收到多个任务申请时，程序按顺序展示，一次只允许确认当前已经提交给微信的申请，不批准尚未展示的排队任务。普通“同意”、群内答复、其他人的命令及未送达/已过期申请都不授权。内部仍保存申请标识用于精确绑定和审计，但申请消息不要求输入该标识。

申请、联系人答复和命令回执进入联系人自己的历史窗口。来源会话只得到工具结果，不读取联系人其他聊天。首次确认有效期默认120秒，本地部署90秒；排队另有上限。拒绝、申请到期、停止、重置、权限收回和重启会阻止后续操作。任务结束后授权不能复用。每次写入都会固定当次沙箱文件内容，等待确认期间文件变化不会替换正在申请的写入内容。

确认等待暂停模型执行超时计时，恢复后继续计算剩余执行时间；不是无限运行。入站和执行前仍检查消息新鲜度，已启动的文件任务不会仅因确认等待后原消息变旧而取消。完成后的群聊结果有独立的新鲜度窗口，并继续受权限、静默、预算和数据缺口约束。真正的执行超时记录为 `turn_timeout`，不再误记成 `source_expired`。

模型不获得命令执行能力。宿主工具拒绝网络路径、设备路径、ADS、链接和硬链接。操作会检查路径，写入使用同目录临时文件替换；不提供递归删除或移动功能。已经批准并完成的文件操作不会因随后取消任务而回滚。

## 部署

`egress.sendArtifacts: true` 开启文件交付。`externalAccess.enabled: true` 开启申请工具；`approver` 必须是私聊白名单中的真实联系人，不能是机器人自己。`maxFileMiB` 为1–10，`timeoutSeconds` 为10–300。未配置授权联系人时不能开启宿主访问。

桥接 `WECHAT_BOT_MEDIA_ROOTS` 只需包含 `agent/data/sandbox`，不开放宿主目录；`WECHAT_BOT_MEDIA_BYTES` 配置为10485760。宿主文件先经批准复制入沙箱，再由桥接按既有收件人白名单发送。修改桥接配置后需要重启桥接。

交互表记录任务来源、执行标识、批准联系人、期限与授权状态。`metadata` 的 `external_operation:<内部标识>` 保留最新操作，附带唯一事件后缀的键保留同一任务各次操作记录；工具失败保留安全错误码，不写入原始错误和凭据。重启不自动恢复未完成授权，不重放旧文件写入。
